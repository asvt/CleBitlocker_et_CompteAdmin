Configurer un PC lycéen via https://asvt.github.io/CleBitlocker_et_CompteAdmin/ en obtenant :
- la clé Bitlocker
- un compte Admin local
- un raccourci vers le dossier perso créé via intune
- des logiciels non disponibles via Ninite (en version portable si problématique via winget)
- des extensions de navigateurs et des polices adaptées au TND

- A ne pas utiliser en dehors du cadre du PC prêté aux lycéens
